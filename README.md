# AllenProject Microservices

This project contains the following Spring Boot microservices using hexagonal architecture:
- product-service
- sales-service
- purchase-service
- warehouse-service
- staff-service

Each service will be structured for PostgreSQL, Liquibase, and Kafka integration.

## Structure
- `/product-service`
- `/sales-service`
- `/purchase-service`
- `/warehouse-service`
- `/staff-service`
- `/docker` (for Docker Compose and Kubernetes manifests)
